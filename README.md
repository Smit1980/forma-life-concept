# FORMA LIFE — архитектурный концепт

Самостоятельный сайт: https://smit1980.github.io/forma-life-concept/

## Локальный просмотр
`python -m http.server 8772 --bind 127.0.0.1` из корня репозитория.

## Архитектурная анимация
Фотореалистичная исходная визуализация `assets/house-large.webp` обработана локально Depth Anything V2 Small (Apache-2.0). Карта относительной глубины: `assets/house-depth.webp`. Два 12-секундных ролика, 1280×960, 30 кадров/с, H.264 без звука: `atria-glide.mp4` и `atria-approach.mp4`. Небольшое движение камеры рассчитано собственным скриптом с обратной проекцией глубины, безопасным запасом по краям и периодической траекторией; код DepthFlow не используется. Исходник и карта сохраняют пропорции 4:3.

Основной вариант — приближение. Сравнение вариантов: `animation-study.html`. Показ начинается после нажатия. Видео загружается по запросу; пауза, повтор, переключение движения, остановка вне экрана, в скрытой вкладке и при общей паузе сайта. Системная настройка уменьшения движения останавливает воспроизведение. При ошибке загрузки доступен исходный рендер и повторная попытка.

Это 2,5D-анимация изображения, а не модель для кругового вращения или достоверной смены материалов. Старый процедурный `viewer.js` больше не подключён. Рабочие чертежи и реальные характеристики уточняются отдельно.

## Сайт
Фильтры, избранное, сравнение и демонстрационные планировки. Шрифты Tenor Sans и Golos Text локальные, OFL в `licenses/`. Форма показывает подготовленное обращение; CRM и отправка данных не подключены.

## Воспроизводимость
Скрипт и проверки в основном workspace: `tools/render_architecture.py`, `tools/qa_architecture.cjs`. Модель и зависимости находятся вне публичного репозитория. Результаты проверки — `evidence/life-photoreal/`.

## Публикация
Push в `main` запускает `.github/workflows/deploy-pages.yml`. Публикуется только корень этого репозитория с публичными файлами сайта.
