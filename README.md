# FORMA LIFE — второй концепт

Отдельная версия по `/life/`, исходный концепт — в корне. Визуальный ориентир: https://highlife.ru/ (масштаб, кадрирование, архитектурная композиция). Фирменные материалы референса не используются.

## Запуск
Из `site/dist`: `python -m http.server 8766 --bind 127.0.0.1`.
Открыть `http://127.0.0.1:8766/life/`. Модули 3D требуют HTTP.

## Состав
- Tenor Sans и Golos Text заменяют все прежние шрифты; self-hosted, кириллица, лицензия OFL в `licenses/`.
- Three.js r180, MIT, локальные ES-модули; загружаются только по нажатию «Открыть 3D».
- Собственная процедурная 3D-модель (эскиз Атриа), материал фасада, освещение, вращение мышью/касанием/клавиатурой. Рендер по запросу, ограничение DPR, поддержка отсутствия WebGL, прокрутка на мобильном не блокируется.
- Фильтры, избранное (только ID проектов в localStorage), сравнение до трёх домов, схемы планировки, комплектации, сценарий обмена, сохранение выбора в демонстрационном обращении.
- Форма валидирует контакты, показывает подготовленное обращение; не отправляет и не сохраняет персональные данные.
- Изображения из существующего концепта, перекодированы в WebP; все проекты демонстрационные. Планировки и 3D-эскиз не являются рабочими чертежами.

Использованные навыки: frontend-design, 3d-web-experience, web-visual-resource-kit. popular-web-designs не найден в доступных каталогах. Источник визуального подхода — предоставленный пользователем High Life.

Автоматизация и CRM не подключены к прототипу. Производственный этап: интеграция выбранной CRM/API, согласование каналов, серверная валидация и диагностика маршрута обращения. Схематичную модель заменяют проектной моделью компании.
