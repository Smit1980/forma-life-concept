# FORMA LIFE — архитектурный концепт

Самостоятельный сайт: https://smit1980.github.io/forma-life-concept/

## Локальный просмотр
Из корня этого репозитория: `python -m http.server 8772 --bind 127.0.0.1`.
Открыть `http://127.0.0.1:8772/`. Для ES-модулей требуется HTTP.

## Архитектурная анимация
- Локальный Three.js r180 (MIT). Модуль загружается после нажатия «Смотреть обзор».
- 40-секундный плавный цикл: архитектура и сад, приближение к террасе, вечерний свет. Камера и освещение интерполируются по времени.
- Пауза, продолжение, сброс ракурса, мышь, касание и стрелки клавиатуры. Ручное вращение прекращает автообзор. Вертикальная прокрутка на телефоне сохранена.
- Процедурные материалы с рельефом, отражающее остекление, вечерние источники света, текстурированная листва и небольшое движение крон.
- Геометрия дома объединена по материалам; листва и травы используют instancing. DPR не выше 1 на телефоне и 1.5 на компьютере.
- Рендер прекращается вне экрана, в скрытой вкладке и после паузы. Уменьшение движения в ОС и общая кнопка паузы сайта отключают автоматическое движение. Ручной выбор света и фасада остаётся доступен.
- При отсутствии или потере WebGL показывается статичное изображение.

## Сайт
Фильтры, избранное (только ID проектов), сравнение, демонстрационные планировки и конфигуратор. Шрифты Tenor Sans и Golos Text размещены локально, лицензии OFL в `licenses/`.
Форма показывает подготовленное обращение; CRM и отправка данных не подключены. Проекты, схемы и 3D-модель демонстрационные, не рабочая проектная документация.

## Публикация
Push в `main` запускает `.github/workflows/deploy-pages.yml`, который публикует корень репозитория в GitHub Pages. Здесь находятся только публичные файлы сайта и лицензии, проверочные отчёты хранятся отдельно в workspace `evidence/life-v2/`.
