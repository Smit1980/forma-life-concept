# Architecture 360 — asset provenance

The house geometry is an authored architectural concept based on the project's source illustration. The back elevation is invented design, not factual reconstruction. Offline Blender Cycles renders are delivered as static WebP frames. Blender is GPL; there is no Blender runtime embedded in this website.

The reference-led second revision uses authored beveled limestone blocks, physical leaf silhouettes, instanced CC0 planting, authored fine lawn geometry, furnished rooms, low-iron glazing and revised asymmetric roof/terrace proportions. These changes improve similarity to the source illustration; they do not establish measured dimensions or recover unseen elevations. Shrub 01 source files were verified against the checksums returned by the official asset API.

Downloaded alternatives Bricks006 and Aerial Grass Rock are not used in the final scene. Source materials, Blender installation and intermediate render files are intentionally excluded from the public Git repository. No externally hosted 3D viewer or paid subscription is required.
